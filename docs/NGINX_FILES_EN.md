# `nginx-telego` Nginx ownership and reconciliation

[Русский](NGINX_FILES.md) · **English**

This document defines the final **P6 — Managed Nginx File Ownership** and **P7 — Reconciliation Engine** contract. P6 identifies ownership and drift; P7 safely reconciles package-owned/generated state to the desired UCI state.

## Source of truth

User-facing ingress configuration:

```text
/etc/config/nginx_telego
```

Versioned ownership registry:

```text
/usr/share/nginx-telego/ownership.tsv
```

Canonical static package copies:

```text
/usr/share/nginx-telego/templates/
├── 20-telego-core.conf
└── telego.locations
```

An active file never becomes canonical merely because it was edited by hand. `package` files are authoritative from their canonical copies; `generated` files are authoritative from UCI/runtime state rendered by nginx-telego.

## Registry v3

`ownership.tsv` contains five TAB-separated fields:

```text
path    role    ownership    presence    source
```

Final P7 layout:

| Path | Role | Ownership | Presence | Source |
|---|---|---|---|---|
| `/etc/nginx/conf.d/20-telego-core.conf` | `core` | `package` | `required` | `/usr/share/nginx-telego/templates/20-telego-core.conf` |
| `/etc/nginx/snippets/telego.locations` | `locations` | `package` | `required` | `/usr/share/nginx-telego/templates/telego.locations` |
| `/etc/nginx/conf.d/80-telego-ingress.conf` | `ingress` | `generated` | `conditional` | `renderer` |
| `/etc/nginx/conf.d/85-telego-fallback.conf` | `fallback` | `generated` | `conditional` | `renderer` |

`nginx-telego` does not claim the whole `/etc/nginx/conf.d/` directory. Unknown administrator/application files remain foreign.

## Ownership

### `package`

A static active file has a canonical package copy. States are:

| State | Meaning |
|---|---|
| `ok` | active file matches the canonical copy |
| `modified` | active regular file has drifted |
| `missing` | active file is absent |
| `invalid-type` | active path is a symlink, directory, FIFO, or another unsupported type |
| `source-missing` | canonical package source is absent |
| `source-invalid-type` | canonical source has an unsafe type |

P7 automatically repairs only safe `modified`/`missing` drift. Unsafe active types or broken canonical sources stop reconciliation.

### `generated`

Generated files must contain the common marker:

```text
# Generated by /usr/libexec/nginx-telego-render from /etc/config/nginx_telego.
```

and the correct role marker:

```text
# nginx-telego-role: ingress
```

or:

```text
# nginx-telego-role: fallback
```

A file with the common marker but the wrong role marker is not adopted; it is classified `foreign`.

For migration from the early P7 implementation, the prior role lines are accepted only for the same role and are rewritten to the canonical marker on the next render.

Generated states:

| State | Meaning |
|---|---|
| `absent` | conditional file is absent |
| `managed` | regular file carries both the common marker and the correct role marker |
| `foreign` | regular file occupies the reserved path without proven ownership |
| `invalid-type` | reserved path has an unsupported type |

## Read-only inventory

```sh
/usr/libexec/nginx-telego-files validate
/usr/libexec/nginx-telego-files list
/usr/libexec/nginx-telego-files status
```

`status` emits:

```text
path    role    ownership    presence    state    source
```

The helper remains read-only: it does not perform `rm`, `mv`, rewrites, Nginx reloads, or UCI mutations.

## Reconciliation Engine

Normal apply path:

```text
LuCI / uci commit
        ↓
procd config.change
        ↓
/etc/init.d/nginx-telego reload
        ↓
/usr/libexec/nginx-telego-reconcile apply
```

The reconciler runs one transaction:

```text
lock
 ↓
validate registry + inventory
 ↓
backup managed state
 ↓
repair safe package drift
 ↓
migrate owned legacy paths
 ↓
renderer apply --no-reload
 ↓
final nginx -t
 ↓
reload only when filesystem state changed
 ↓
commit
```

If rendering, final `nginx -t`, or reload fails, managed filesystem state is rolled back to its pre-transaction bytes.

Only one reconciler may run at a time. An active lock rejects overlap; a stale lock is recovered automatically.

## Legacy migration

P7 handles two historical paths automatically.

### `/etc/nginx/conf.d/zz-telego-managed.conf`

The old combined generated file is removed/migrated only when its historical package marker proves ownership. A foreign regular file is preserved. A symlink, directory, FIFO, or other unsafe type stops automatic migration.

### `/etc/nginx/conf.d/telego.conf`

The old static core is removed automatically only when its bytes match the canonical core. A changed regular file is preserved and blocks automatic migration so administrator content is never silently discarded. Unsafe types also stop migration.

After successful P7 migration the active package layout uses only `20-*`, `80-*`, `85-*`, plus `telego.locations`.

## Uninstall

Generated cleanup is also coordinated through the reconciler:

```sh
/usr/libexec/nginx-telego-reconcile remove-generated
```

The package `prerm` uses this path instead of mutating generated files directly through the renderer. LuCI/procd/uninstall therefore share one lock and one outer `nginx -t` / rollback boundary.

Foreign files on reserved paths are preserved.

## Registry security boundary

The registry is not an arbitrary root-filesystem manifest. Validation requires:

- absolute clean paths with no `..`, `.` or empty segments;
- `core`, `ingress`, and `fallback` only as direct `/etc/nginx/conf.d/*.conf` children;
- `locations` only as a direct `/etc/nginx/snippets/` child;
- package sources only under `/usr/share/nginx-telego/templates/`;
- valid `role / ownership / presence` combinations;
- no duplicate managed paths;
- a non-empty source.

P7 write operations therefore inherit the already constrained P6 namespace.

## CI

The contract is verified at multiple levels:

1. ownership tests: drift, canonical-source failures, symlink/directory/FIFO cases, path boundaries, and role markers;
2. renderer tests: Cloudflare/Native contracts, conflicts, role-aware ownership, and atomic rollback;
3. reconciler tests: package repair, core/generated migration, `nginx -t`/reload rollback, foreign files, fallback transitions, active/stale locks, and uninstall cleanup;
4. APK layout verification: final package paths, modes, ownership, and absence of legacy/generated payloads;
5. OpenWrt rootfs smoke: real APK installation, `nginx-telego-files validate/status`, legacy migration, and remove/reinstall lifecycle.

## P8 boundary

P6/P7 mutate only files owned by `nginx-telego` and preserve foreign state. P8 will add LuCI inventory plus explicit administrator operations for custom/foreign `.conf` files: disable/quarantine, restore, delete, diff, repair, and a later restricted editor. Until P8, a foreign file is never deleted or adopted automatically.
